# ScriptDepo ⚡

Modern, mobile-first Roblox script discovery and sharing MVP.

## Features
- Premium dark UI
- Search and game/tag filters
- Popular / newest / views sorting
- Script detail modal and copy button
- Categories
- Community publish demo
- LocalStorage demo persistence
- Responsive mobile layout

## Architecture
This first version is a static client-side MVP. It does not execute scripts. A production version should add authentication, database, moderation, rate limiting and server-side validation.

## Run
Open `index.html` or deploy the repository with GitHub Pages / another static host.
